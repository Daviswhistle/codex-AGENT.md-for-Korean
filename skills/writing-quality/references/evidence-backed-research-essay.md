# 근거 기반 조사 에세이 프로필

## 적용 범위

다음 두 조건을 모두 만족할 때 이 프로필을 적용한다.

1. 주요 산출물이 독자가 그대로 읽는 장문 조사 에세이·분석 칼럼·반복 브리핑이거나, 사용자가 출고 가능한 깊이와 별도 검수를 명시한다.
2. 다음 가운데 하나 이상이 결론이나 신뢰에 실질적으로 영향을 준다.
   - 과거 답변과 질문·메커니즘·사례·교훈의 의미상 중복을 피해야 한다.
   - 연대기, 상대적 시간 관계, 회계기간, 실제값·전망·추정·모형값을 잘못 연결할 위험이 있다.
   - 주장별 출처 성격과 인과 강도를 분리해야 한다.
   - 오독 비용이 커서 주장표나 분리 검수가 품질을 실질적으로 높인다.

짧은 출처 기반 질의응답, 단일 사실 확인, 한두 문장 교정, 간단한 기술 설명에는 출처를 사용한다는 이유만으로 이 프로필을 적용하지 않는다. 필요한 사실 확인과 전역 최소 글쓰기 기준만 적용한다.

이 프로필은 고정 목차가 아니다. 초안 전에 필요한 증거 구조를 만들고, 초안 뒤에 사실 검수와 출력 언어 편집을 분리하는 작업 계약이다.

## 완료 조건

완성 원고는 다음을 모두 만족해야 한다.

1. 사용자의 질문 하나에 직접 답하고 중심 주장을 한 문장으로 말할 수 있다.
2. 반복 작업이라면 과거 원장과 질문·메커니즘·교훈의 결합이 실질적으로 다르다. 제목과 사례만 바꾼 동일 판단은 새 글로 세지 않는다.
3. 중심 주장과 결론을 떠받치는 사실·수치·인과가 주장표에 연결돼 있다.
4. 시간 관계가 결론이나 비교에 실질적으로 영향을 주면 사건표가 있고, 그렇지 않으면 `사건표: 해당 없음`의 이유가 타당하다.
5. 적용되는 경우 연대기, 회계기간, 비교 기준, 실제값·전망·추정·모형값 구분에 내부 모순이 없다.
6. 가능한 1차 자료를 우선하고 출처가 허용하는 강도보다 문장을 세게 쓰지 않는다.
7. 독자가 원문 언어나 조사 과정의 흔적을 해독하지 않아도 된다.
8. 사실 검수와 출력 언어 편집에서 남은 중대한 지적이 없다.

## 작성 전 작업 묶음

사용자가 요구하지 않으면 아래 작업물은 내부 검증용으로만 유지한다. 빈칸이나 추정으로 채운 형식적 표는 만들지 않는다.

### 1. 주제 원장과 중복 감사

반복 작업의 과거 답변과 후보를 다음 네 축으로 요약한다.

| 필드 | 의미 |
|---|---|
| 질문 유형 | 독자가 무엇을 판단하려고 묻는가 |
| 핵심 메커니즘 | 결과를 만든 인과 또는 선택 구조가 무엇인가 |
| 대표 사례 | 어떤 사건·연구·기업·제도를 사용하는가 |
| 최종 교훈 | 독자가 무엇을 다르게 판단하거나 관찰해야 하는가 |

중복은 네 축을 따로 세어 판정하지 않고 **질문·메커니즘·교훈의 결합**을 의미적으로 비교한다.

- 질문이 사실상 같고, 같은 메커니즘으로, 같은 판단 또는 행동에 도달하며 사례만 바뀌면 중복이다.
- 핵심 메커니즘 하나가 같더라도 다른 질문에 적용되어 결론과 판단이 달라지면 새 글일 수 있다.
- 일반적인 교훈 하나가 같더라도 그 교훈에 도달하는 인과 구조와 적용 판단이 다르면 새 글일 수 있다.
- 제목·고유명사·키워드 불일치만으로 새 주제로 승인하지 않는다.
- 경계 사례는 어느 축이 같고 다른지, 그 차이가 독자의 판단을 실제로 바꾸는지 한두 문장으로 기록한다.

중복이면 후보를 폐기하거나 질문·메커니즘·교훈 중 적어도 하나가 실질적으로 달라지도록 다시 설계한다.

### 2. 다섯 줄 논리 설계

1. 직접 답할 한 문장
2. 그 답을 만드는 핵심 메커니즘
3. 빠지면 결론이 무너지는 중간 단계
4. 가장 강한 반대 근거 또는 범위 제한
5. 글이 도달할 판단이나 실용적 적용

자료에 따라 중심 주장이 바뀌면 주장표와 적용되는 사건표도 갱신한다. 이미 모은 자료를 살리기 위해 약한 논지를 유지하지 않는다.

### 3. 주장표

중심 주장과 판단에 영향을 주는 보조 주장마다 다음을 기록한다.

| 필드 | 내용 |
|---|---|
| 주장 | 본문에서 말하려는 정확한 문장 |
| 역할 | 중심 주장·메커니즘·반론·한계·적용 중 무엇인가 |
| 근거 | 어떤 자료의 어느 결과가 뒷받침하는가 |
| 출처 성격 | 공식 통계·공시·논문·기업 발표·보도·논평 등 |
| 상태 | 관측값·추정치·전망·시나리오·모형 결과 |
| 범위 | 대상, 기간, 지역, 표본, 조건 |
| 확신과 한계 | 무엇까지 말할 수 있고 무엇은 말할 수 없는가 |
| 본문 위치 | 어느 문단에서 어떤 역할로 쓰이는가 |

한 출처가 관련 주제를 언급한다는 이유만으로 특정 수치나 인과를 지지한다고 기록하지 않는다. 주장 가까이에 놓일 출처가 문장 전체를 실제로 뒷받침하는지 확인한다.

### 4. 조건부 사건표

사건표는 **연대기, 상대적 시간 표현, 기간 간 비교, 또는 전망에서 실제값으로의 상태 변화가 중심 주장이나 결론을 실질적으로 지탱할 때** 초안 전에 만든다.

다음만으로는 사건표를 의무화하지 않는다.

- 논문 발표 연도나 회사 설립 연도를 배경으로 한 번 언급한다.
- 같은 시점의 횡단면 자료에 조사 기간을 표시한다.
- 결론이나 비교에 영향을 주지 않는 부수적 날짜가 있다.

사건표가 필요 없으면 `사건표: 해당 없음`과 그 이유를 기록한다. 숨은 상대 비교나 변화 주장이 없는지도 확인한다.

| 필드 | 내용 |
|---|---|
| 사건 날짜 | 발표·시행·발생 날짜 |
| 대상 기간 | 실적·연구·정책이 집계한 기간 |
| 회계기간 | 회계연도와 분기, 필요하면 달력연도와의 차이 |
| 수치와 단위 | 원자료의 값과 단위 |
| 수치 성격 | 실제 실적·당시 전망·후대 추정·모형값 |
| 비교 기준 | 전년 동기·직전 분기·누적·대조군 등 |
| 원자료 | 해당 행을 직접 뒷받침하는 출처 |
| 서사 역할 | 도입·전환·반론·결론 중 어디에 쓰이는가 |

`몇 달 뒤`, `직전 분기`, `그해`, `이후` 같은 표현은 사건표의 행 사이에 실제로 성립할 때만 사용한다. 중간 사건을 생략해 서로 다른 수치를 같은 기간이나 직접 비교값처럼 보이게 하지 않는다.

### 5. 용어와 출력 표면 계약

모든 출력 언어에서 다음을 지킨다.

- 같은 개념의 명칭, 약어, 대소문자, 단위 표기를 일관되게 유지한다.
- 원문 URL, 검색결과 제목, `[Image]`, 도구 호출 표식, JSON, 내부 메모, 임시 제목을 독자용 본문에 남기지 않는다.
- 사용자가 원문 링크나 참고문헌을 요구하면 본문 흐름과 분리해 정리한다.

한국어 원고에서는 자연스러운 한국어를 우선하고 정확한 원어가 필요할 때만 첫 등장에 한 번 병기한다. 영어 원고에서는 한국어 어순과 번역된 명사 연쇄를 피하고 해당 분야의 표준 영어 표현을 쓴다.

## 조사와 초안

1. 사례의 비범함보다 증거의 식별력과 실용적 관련성을 먼저 본다.
2. 공식 자료, 원 논문, 공시, 행정통계 등 1차 자료를 우선한다.
3. 다섯 줄 설계와 주장표에 기여하지 않는 자료는 버린다.
4. 원문의 문장 순서를 따라 번역하지 않고 이해한 인과를 출력 언어 독자의 처리 순서로 쓴 뒤 원자료와 다시 대조한다.
5. 각 문단은 앞 문단이 만든 의문에 답하거나 다음 판단에 필요한 조건을 추가한다.
6. 반론과 한계는 결론을 실제로 바꾸는 것만 남긴다.
7. 실용적 적용은 사례의 구조에서 직접 따라올 때만 쓴다.

## 분리 검수

### 사실 검수

이 프로필을 선택한 작업에서는 초안 뒤 `../agents/research_fact_reviewer.md`를 읽고 사실 검수 패스를 수행한다. 가능한 경우 초안 작성과 분리된 문맥이나 하위 에이전트에서 실행한다. 그런 실행 환경이 없으면 같은 문맥에서 초안 작성과 구분된 별도 패스로 수행하되 독립 검수라고 표현하지 않는다. 다음을 판정한다.

- 사건표가 실제로 필요한 글인지, 필요하다면 본문 날짜·기간·수치와 일치하는가
- 사건표가 `해당 없음`인 글에 숨은 시간 비교가 없는가
- 전망·실적·추정·모형값이 섞이지 않았는가
- 출처가 주장 전체를 뒷받침하는가
- 회사 설명, 관찰연구, 실험, 모형, 후대 해석의 증거 강도를 구분했는가
- 질문·메커니즘·교훈의 결합이 과거 원장과 실질적으로 다른가

중심 사실이나 적용되는 연대기 오류가 하나라도 남으면 출고하지 않는다.

### 출력 언어 편집

사실 검수의 중대한 지적을 해결한 뒤 출력 언어에 맞는 편집기 파일을 읽고 사실 검수와 구분된 편집 패스를 수행한다.

- 한국어 원고: `../agents/korean_research_editor.md`
- 영어 원고: `../agents/english_research_editor.md`

가능하면 분리된 문맥이나 하위 에이전트에서 실행한다. 사용할 수 없으면 같은 문맥의 별도 패스로 수행하되 독립 편집이라고 표현하지 않는다. 편집자는 새 사실을 넣지 않고 구조·용어·관용성·중복·표면 잔재를 검수한다. 편집이 사실·숫자·날짜·비교 기준·인과 강도를 바꾸면 사실 검수로 되돌린다.

주제 원장, 주장표, 사건표와 검수 기록은 사용자가 요구하지 않으면 독자용 최종 출력에 노출하지 않는다.

## 출고 중단 조건

다음 가운데 하나라도 남으면 출고하지 않는다.

- 중심 주장과 핵심 근거가 주장표에 연결되지 않았다.
- 필요한 사건표가 없거나 사건표와 본문이 충돌한다.
- 시간축이 없다고 했지만 숨은 변화·순서·상대 비교가 있다.
- 과거 원장과 질문·메커니즘·교훈의 결합이 실질적으로 같다.
- 실제값·전망·외부 추정·모형값을 같은 확신도로 썼다.
- 회사가 확인한 사실과 외부 설명 모형을 구분하지 않았다.
- 출력 언어에 맞지 않는 번역투·용어 혼용·조사 표면이 남았다.
- 사실 검수 또는 언어 편집의 P1·P2가 해결되지 않았다.
