# 근거 기반 조사 에세이 프로필

## 적용 범위

다음 두 조건을 모두 만족할 때 이 프로필을 적용한다.

1. 주요 산출물이 독자가 그대로 읽는 장문 조사 에세이·분석 칼럼·반복 브리핑이거나, 사용자가 출고 가능한 수준의 깊이와 별도 검수를 명시한다.
2. 다음 가운데 하나 이상이 글의 결론이나 신뢰에 실질적으로 영향을 준다.
   - 과거 답변과 질문·메커니즘·사례·교훈의 중복을 피해야 한다.
   - 날짜, 회계기간, 사건 순서, 실제값·전망·추정·모형값을 잘못 연결할 위험이 있다.
   - 주장별 출처 성격과 인과 강도를 분리해야 한다.
   - 오독 비용이 커서 주장표나 분리 검수가 품질을 실질적으로 높인다.

짧은 출처 기반 질의응답, 단일 사실 확인, 간단한 기술 설명에는 출처를 사용한다는 이유만으로 이 프로필을 적용하지 않는다. 필요한 사실 확인과 전역 최소 글쓰기 기준만 적용한다.

이 프로필은 고정 목차가 아니다. 초안을 쓰기 전에 필요한 증거 구조를 만들고, 초안 뒤에 사실 검수와 출력 언어에 맞는 편집을 분리하는 작업 계약이다.

## 완료 조건

완성 원고는 다음을 모두 만족해야 한다.

1. 사용자의 질문 하나에 직접 답하고, 중심 주장은 한 문장으로 말할 수 있다.
2. 반복 작업이라면 과거 원장과 실질적으로 겹치지 않는다. 제목이나 사례만 바꾼 동일 메커니즘·동일 교훈은 새 글로 세지 않는다.
3. 중심 주장과 결론을 떠받치는 사실·수치·인과가 주장표에 연결돼 있다. 날짜·기간·순서·변화 주장이 있으면 사건표에도 연결돼 있고, 없으면 사건표를 `해당 없음`으로 판정한 이유가 타당하다.
4. 적용되는 경우 연대기, 회계기간, 비교 기준, 실제값·전망·추정·모형값의 구분에 내부 모순이 없다.
5. 가능한 1차 자료를 우선하고, 출처가 실제로 뒷받침하는 강도보다 문장을 세게 쓰지 않는다.
6. 독자가 원문 언어나 조사 과정의 흔적을 해독하지 않아도 된다.
7. 사실 검수와 출력 언어에 맞는 편집에서 남은 중대한 지적이 없다.

## 작성 전 작업 묶음

사용자가 요구하지 않으면 아래 작업물은 내부 검증용으로만 유지한다. 표를 만든 사실 자체가 품질을 보장하지 않으므로 내용이 비어 있거나 추정으로 채워진 형식적 표는 만들지 않는다.

### 1. 주제 원장

반복 작업에서는 과거 답변을 다음 네 축으로 요약한다.

| 필드 | 의미 |
|---|---|
| 질문 유형 | 사용자의 어떤 질문에 답했는가 |
| 핵심 메커니즘 | 결과를 만든 인과 구조는 무엇인가 |
| 대표 사례 | 어떤 사건·연구·기업·제도를 사용했는가 |
| 최종 교훈 | 독자가 무엇을 다르게 판단하거나 관찰해야 하는가 |

후보 주제와 원장을 대조한다. 핵심 메커니즘 또는 최종 교훈이 같으면 대표 사례가 달라도 중복으로 판정한다. 중복 여부를 제목·고유명사·키워드 일치로만 판단하지 않는다. 경계가 불분명하면 새 주제를 선택한다.

### 2. 다섯 줄 논리 설계

1. 직접 답할 한 문장
2. 그 답을 만드는 핵심 메커니즘
3. 빠지면 결론이 무너지는 중간 단계
4. 가장 강한 반대 근거 또는 범위 제한
5. 글이 도달할 판단이나 실용적 적용

자료를 찾을수록 이 설계가 바뀔 수 있다. 중심 주장이 바뀌면 주장표와, 적용되는 경우 사건표도 갱신한다. 이미 모은 자료를 살리기 위해 약한 논지를 유지하지 않는다.

### 3. 주장표

중심 주장과 판단에 영향을 주는 보조 주장마다 다음을 기록한다.

| 필드 | 내용 |
|---|---|
| 주장 | 본문에서 말하려는 정확한 문장 |
| 역할 | 중심 주장·메커니즘·반론·한계·적용 중 무엇인가 |
| 근거 | 어떤 자료의 어느 결과가 뒷받침하는가 |
| 출처 성격 | 공식 통계·공시·논문·기업 발표·보도·논평 등 |
| 상태 | 관측값·추정치·전망·시나리오·모형 결과 |
| 범위 | 대상, 기간, 지역, 표본, 조건 |
| 확신과 한계 | 무엇까지 말할 수 있고 무엇은 말할 수 없는가 |
| 본문 위치 | 어느 문단에서 어떤 역할로 쓰이는가 |

한 출처가 관련 주제를 언급한다는 이유만으로 특정 수치나 인과를 지지한다고 기록하지 않는다. 주장 가까이에 놓일 출처가 그 문장 전체를 실제로 뒷받침하는지 확인한다.

### 4. 사건표

날짜·기간·순서·변화 주장이 들어가는 글은 초안 전에 사건표를 만든다. 그런 주장이 없으면 `사건표: 해당 없음`과 이유를 기록하고 형식적인 표를 만들지 않는다.

| 필드 | 내용 |
|---|---|
| 사건 날짜 | 발표·시행·발생 날짜 |
| 대상 기간 | 실적·연구·정책이 집계한 기간 |
| 회계기간 | 회계연도와 분기, 필요하면 달력연도와의 차이 |
| 수치와 단위 | 원자료의 값과 단위 |
| 수치 성격 | 실제 실적·당시 전망·후대 추정·모형값 |
| 비교 기준 | 전년 동기·직전 분기·누적·대조군 등 |
| 원자료 | 해당 행을 직접 뒷받침하는 출처 |
| 서사 역할 | 도입·전환·반론·결론 중 어디에 쓰이는가 |

`몇 달 뒤`, `직전 분기`, `그해`, `이후` 같은 표현은 사건표의 행 사이에 실제로 성립할 때만 사용한다. 중간 사건을 생략하면 독자가 서로 다른 수치를 같은 기간이나 직접 비교값으로 오해할 수 있는지 점검한다.

### 5. 용어와 출력 표면 계약

모든 출력 언어에서 다음 원칙을 쓴다.

- 같은 개념의 명칭, 약어, 대소문자, 단위 표기를 일관되게 유지한다.
- 원문 URL, 검색결과 제목, `[Image]`, 도구 호출 표식, JSON, 내부 메모, 임시 제목, 수식용 코드 블록을 독자용 본문에 남기지 않는다.
- 사용자가 원문 링크나 참고문헌 목록을 요구하면 본문 흐름과 분리해 정리한다.

한국어 원고에서는 다음을 추가한다.

- 자연스러운 한국어 번역이 있으면 한국어를 우선한다.
- 정확한 검색어·법률명·공시 지표·업계 약어가 필요한 경우 첫 등장에만 한국어 뒤 괄호로 원어를 병기한다.
- 같은 개념을 한국어와 영어로 번갈아 부르지 않는다.

영어 원고에서는 다음을 추가한다.

- 한국어 어순, 생략된 주어, 번역된 명사 연쇄를 옮기지 않고 자연스러운 영어의 정보 순서로 쓴다.
- 전문 용어는 해당 분야의 표준 영어 표현을 쓰고, 불필요한 한국어 병기나 직역 표현을 남기지 않는다.

## 조사와 초안

1. 사례의 비범함보다 증거의 식별력과 실용적 관련성을 먼저 본다. 놀라운 사례라도 중심 인과를 분리할 수 없으면 보조 사례로 낮추거나 버린다.
2. 공식 자료, 원 논문, 공시, 행정통계 등 1차 자료를 우선한다. 2차 자료는 원자료 발견, 맥락, 반론 파악에 사용하고 중심 수치가 가능하면 원자료로 돌아간다.
3. 자료를 많이 모았다는 흔적을 본문에 보존하지 않는다. 다섯 줄 논리 설계와 주장표에 직접 기여하지 않는 자료는 버린다.
4. 조사가 끝나면 원문의 문장 순서를 따라 번역하지 말고, 자료를 덮은 상태에서 이해한 인과를 출력 언어 독자의 처리 순서로 초안화한다. 그 뒤 원자료를 다시 열어 의미와 수치를 대조한다.
5. 각 문단은 앞 문단이 만든 의문에 답하거나 다음 판단에 필요한 조건을 추가해야 한다. 관련 자료가 하나 더 있다는 이유만으로 문단을 붙이지 않는다.
6. 반론과 한계는 결론을 실제로 바꾸는 것만 남긴다. 의례적인 양비론이나 모든 가능성의 열거는 하지 않는다.
7. 실용적 적용은 사례의 구조에서 직접 따라올 때만 쓴다. 투자·AI·사업에 억지로 연결하지 않는다.

## 분리 검수

### 사실 검수

가능하면 초안 작성과 분리된 문맥에서 `../agents/research_fact_reviewer.md`를 적용한다. 검수자는 문체를 고치지 않고 다음을 판정한다.

- 사건표가 필요한 글인지, 필요하다면 본문 날짜·기간·수치와 일치하는가
- 사건표가 `해당 없음`인 글에 숨은 시간 비교가 없는가
- `직전`, `이후`, `전년`, `누적` 같은 관계가 실제로 맞는가
- 전망·실적·추정·모형값이 섞이지 않았는가
- 출처가 주장 전체를 뒷받침하는가
- 상관관계, 자연실험, 무작위실험, 모형 결과의 인과 강도를 구분했는가
- 경쟁 설명과 경계 조건이 결론의 확신도에 반영됐는가

중심 사실이나 적용되는 연대기 오류가 하나라도 남으면 원고를 출고하지 않는다.

### 출력 언어 편집

사실 검수의 중대한 지적을 해결한 뒤 출력 언어에 맞는 편집기를 별도 문맥에서 적용한다.

- 한국어 원고: `../agents/korean_research_editor.md`
- 영어 원고: `../agents/english_research_editor.md`

편집자는 새 사실을 넣지 않고 다음을 판정한다.

- 출력 언어에 부자연스러운 번역투나 원문 어순이 남지 않았는가
- 같은 개념의 명칭이 일관되는가
- 문단마다 역할이 하나이고 인과가 앞으로 나아가는가
- 같은 결론을 다른 표현으로 반복하지 않는가
- 소제목, 목록, 짧은 문장이 기능 없이 늘어나지 않았는가
- 조사 메모, URL, 이미지 표식, 도구 흔적이 본문에 새지 않았는가
- 결말이 앞의 요약을 되풀이하지 않고 자연스럽게 도달하는가

편집으로 주장 강도, 수치, 날짜, 비교 기준, 인과관계가 바뀌면 사실 검수를 다시 거친다.

## 출고 중단 조건

다음 중 하나라도 맞으면 완성 원고로 내보내지 않는다.

- 반복 작업에서 과거 원장과의 중복 여부가 해결되지 않았다.
- 중심 주장이 한 문장으로 정리되지 않거나 자료가 그 주장을 지지하지 않는다.
- 사건표가 필요한데 없거나, 사건표와 본문의 시간순서가 충돌한다.
- 시간축이 있는데 사건표를 `해당 없음`으로 처리한다.
- 실제값, 전망, 추정, 모형값 가운데 하나를 다른 것으로 서술한다.
- 비교 기준이나 분모가 불명확한 핵심 수치가 남아 있다.
- 1차 자료를 확인할 수 있는데도 약한 2차 자료만으로 중심 주장을 세운다.
- 회사 발표가 확인한 사실과 후대 연구자의 가설·모형을 같은 수준의 확정 사실로 쓴다.
- 사실 검수의 P1·P2 또는 출력 언어 편집의 P1·P2가 해결되지 않았다.
- 원문 링크, `[Image]`, 불필요한 원어, 내부 작업표가 독자용 본문에 남아 있다.

## 최종 출력

사용자가 작업 과정이나 근거표를 요청하지 않았다면 완성된 원고만 제공한다. 주제 원장, 주장표, 사건표와 검수 기록은 품질을 만들기 위한 내부 산출물이지 독자가 조립해야 할 부속품이 아니다.
