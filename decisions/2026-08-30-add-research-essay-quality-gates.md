# 근거 기반 조사 에세이 품질 게이트 추가

날짜: 2026-08-30

## 결정

모든 사용자 대상 답변에는 전역 최소 글쓰기 기준을 적용한다. 글쓰기 자체가 주요 품질 병목인 작업에는 기존 `writing-quality` 스킬을 사용하고, 그중 장문·반복 발행 근거 기반 조사에는 별도 프로필을 적용한다.

조사 프로필은 다음을 초안 전에 관리한다.

- 반복 작업의 질문·메커니즘·사례·교훈 중복
- 중심 주장과 주장별 근거
- 결론을 지탱하는 연대기·기간 비교와 실제값·전망·추정·모형값 구분
- 회사가 확인한 사실과 외부 설명 모형의 증거 강도

사실 검수와 문장 편집은 분리한다. 한국어 원고에는 한국어 편집기, 영어 원고에는 영어 편집기를 적용한다.

## 적용 경계

- 짧은 출처 기반 질의응답, 단일 사실 확인, 한두 문장 교정에는 무거운 작업 묶음을 적용하지 않는다.
- 사건표는 날짜가 존재한다는 이유가 아니라, 연대기·상대적 시간 관계·기간 비교·전망에서 실제값으로의 변화가 중심 주장이나 결론을 실질적으로 지탱할 때만 만든다.
- 발표 연도, 회사 설립 연도, 조사 기간처럼 결론에 영향을 주지 않는 부수적 날짜만 있으면 `사건표: 해당 없음`과 이유를 기록할 수 있다.
- 작업표와 검수 기록은 사용자가 요구하지 않으면 독자용 출력에 노출하지 않는다.
- 편집 과정에서 사실·수치·비교 기준·인과 강도가 바뀌면 사실 검수로 되돌린다.

## 구조

- `AGENTS.md`: 모든 답변의 최소 글쓰기 기준과 스킬 라우팅
- `skills/writing-quality/SKILL.md`: 작업 규모에 따른 작성·검수 절차와 조사 프로필의 명시적 로드 경계
- `references/evidence-backed-research-essay.md`: 조사 프로필의 주장표·조건부 사건표·중복 감사
- `agents/research_fact_reviewer.md`: 사실·연대기·수치·출처·인과 검수
- `agents/korean_research_editor.md`: 한국어 구조·용어·리듬·출력 표면 검수
- `agents/english_research_editor.md`: 영어 구조·용어·관용성·출력 표면 검수
- `references/research-essay-evaluation.md`: 실제 실패를 재현하는 차등 평가

## 제외한 범위

이 변경에서는 범용 `agents/openai.yaml` 파서나 저장소 전체 메타데이터 스키마 검증기를 만들지 않는다. 현재 스킬 메타데이터는 공식 형식에 맞게 직접 정리한다.

범용 메타데이터 검증이 필요해지면 별도 변경으로 다룬다. 그때는 YAML 일부를 직접 재구현하지 않고 실제 YAML 파서 또는 공식 생성기와 작은 공개 스키마를 사용한다.

## 검증과 현재 증거

정적 검증은 저장소 구조, 독립 설치 가능성, 참조 경로와 기존 테스트가 깨지지 않았는지를 확인한다. 글쓰기 품질은 같은 모델·추론 수준·입력으로 기준선과 후보를 여러 독립 문맥에서 실행해 비교한다.

교정된 설치 평가에서 기준선과 후보의 최종 출력은 각각 6/6로 같았고, 후보의 새 조사 reference·검수기·편집기는 0/6회 읽혔다. 따라서 현재까지 확인된 것은 사용자 대상 출력 회귀가 없다는 점뿐이며, 새 조사 경로의 품질 향상은 입증되지 않았다. 명시적 reference 로드 계약을 수정한 뒤 더 현실적인 입력으로 다시 평가하고, 실제로 관측된 차이만 기록한다.
