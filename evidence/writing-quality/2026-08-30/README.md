## 상태

이 디렉터리는 `writing-quality` 조사 에세이 프로필과 경계 수정의 실제 행동 평가를 보존한다. 평가 명세만으로 품질 개선을 주장하지 않고, 실행에서 관측된 차이와 관측되지 않은 차이를 구분한다.

현재 영구 기록된 평가는 리뷰 대상 커밋 `032b5b1cd9ae11ac6bc826807bf62eade30196dd`와 수정 후보 `c90adb5b589232c518c8b608f5247621f6885697`을 비교한 세 사례·여섯 독립 실행이다. 정확한 프롬프트와 전체 출력은 `boundary-evaluation.md`, 판정은 `manual-grades.json`에 있다.

## 실행 조건

- 실행 문맥: 각 변형과 사례마다 `fork_turns=none`인 새 독립 문맥
- 모델: GPT-5.6 Sol
- 추론 수준: 실행 API가 명명된 수준을 노출하지 않아 동일 플랫폼 기본값으로만 기록한다. `medium` 또는 `high`로 추정하지 않는다.
- 네트워크: 금지
- 파일 수정: 금지
- 종료 상태: 여섯 실행 모두 `completed`
- 비교 통제: 같은 사례의 두 변형에는 동일한 사용자 입력을 제공했다.
- 원출력 출처: PR #45의 Codex review comment `3888862985`

## 해석 경계

이 여섯 실행에서 직접 확인된 개선은 영어 편집기 라우팅이다. 짧은 질의응답과 시간축 없는 글의 수정은 계약을 명료하게 만들고 미래 회귀를 막는 방어선이지만, 이 표본에서는 수정 전후 출력 차이가 관측되지 않았다. 따라서 두 항목을 측정된 품질 개선으로 표현하지 않는다.

별도의 여덟 실행에서는 수정 후보 `c90adb5`가 짧은 출처 기반 답변에 조사 프로필을 노출하지는 않았지만 내부적으로 축약된 다섯 줄 설계를 수행한 것으로 보고됐다. 해당 작업은 원출력 파일을 GitHub 브랜치에 푸시하지 못했으므로 이 디렉터리의 영구 원출력 증거로 세지 않는다. 다만 발견된 회귀는 상위 라우팅과 공통 작성 절차를 다시 좁히는 근거가 됐고, 후속 커밋 `a2d9826cc4af315422c8e8d76aa8b2847a497bc9`에서 짧고 원자적인 답변은 작업표·다섯 줄 설계·분리 검수를 건너뛰도록 수정했다.

현재 HEAD에 대한 재실행 결과가 확보되면 기존 기록을 덮지 않고 별도 절에 추가한다. 원출력이나 실행 메타데이터가 없는 실행을 완료된 증거로 소급해 기록하지 않는다.
