## 첫 12회 평가: 스킬 효과 비교 무효

숨겨진 중간 분기와 의미 중복 과제를 기준선과 후보에 각각 세 번 실행한 첫 결과는 baseline 6/6, candidate 6/6이었다. 그러나 각 snapshot의 `writing-quality`를 `$CODEX_HOME/skills/writing-quality/`에 설치하지 않았고 raw trace에도 스킬·reference 로드가 없었다.

따라서 이 실행은 같은 입력에서 기본 모델이 두 과제를 해결했고 후보의 출력 회귀가 없었다는 확인에만 사용한다. 후보 스킬이나 새 조사 프로필의 효과 증거로는 사용하지 않는다. 출처는 PR #46 댓글 `5468477219`다.

## 교정된 12회 설치 평가

댓글 `5468614327`의 교정 평가에서는 각 실행마다 격리된 `CODEX_HOME`을 만들고 해당 commit의 `writing-quality`를 설치했다.

- 12회 모두 설치된 `SKILL.md`를 실제로 읽은 흔적이 확인됐다.
- 숨겨진 중간 분기: baseline 3/3, candidate 3/3
- 의미 중복과 과잉 차단: baseline 3/3, candidate 3/3
- 전체 최종 출력: baseline 6/6, candidate 6/6, 차이 0%p
- candidate의 `references/evidence-backed-research-essay.md`, 사실 검수기, 출력 언어 편집기 로드: 0/6

따라서 기본 `writing-quality` 스킬의 설치와 로드는 유효하게 비교됐지만, 이번 PR이 새로 추가한 조사 프로필·검수기·중복 감사 경로의 행동 효과는 입증되지 않았다. 최종 출력 성공률의 개선이나 악화도 관측되지 않았다.

## 현재 판단과 다음 평가

`SKILL.md`에서 조건을 만족하는 작업이 조사 reference를 실제로 읽도록 라우팅 계약을 명시하고, 평가 입력이 정답과 판별 축을 직접 가르치지 않도록 수정한다.

수정된 head에서는 다음을 다시 각각 세 번 실행한다.

1. 2분기 누락, 전망과 실제값 혼동, 회사 사실과 후대 모형 혼동이 포함된 결함 초안 교정
2. 판별 축을 알려 주지 않은 의미 중복과 과잉 차단 판단
3. 짧은 출처 기반 답변에서 조사 reference와 검수기가 로드되지 않는 경계
4. 부수적 날짜가 있는 비시간축 글과 영어 원고의 언어 편집 경계

새 조사 reference와 필요한 검수기 로드가 추적에서 확인되고 기준선 대비 실제 개선이 반복적으로 관측되기 전에는 핵심 품질 향상을 입증했다고 표현하지 않는다. 현재 PR은 병합 준비 완료가 아니다.
