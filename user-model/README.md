# User Model

이 디렉터리는 작업 재현성에 필요한 사용자 기준 중 아직 `AGENTS.md`, guideline, checklist, skill, template 같은 실행 원본으로 흡수되지 않은 것만 위한 자리다.

과거 피드백의 연대기나 승격 이력은 유지하지 않는다. 기준이 충분히 확인되어 실제 동작을 바꿔야 하면 적절한 규범 원본에 직접 반영하고, 왜 바뀌었는지는 Git commit/PR에서 확인한다.

새 파일을 추가할 때는 다음을 모두 만족해야 한다.

1. 다음 작업의 판단이나 결과를 실제로 바꾼다.
2. 다른 규범 원본에 넣으면 역할이 왜곡된다.
3. 현재도 유효하고 사용자에게 공개 가능한 내용이다.
4. 계정·토큰·비밀번호·민감정보·비공개 원문을 포함하지 않는다.
5. 같은 내용을 다른 파일에 중복 저장하지 않는다.

이 조건을 만족하지 않으면 기록하지 않는다.
